**改已有课程**：保留原来的 `id`，这样学生收藏的链接仍能打开。比如，要改《题西林壁》的纸山活动，打开“小学语文”，搜索“换个角度试一试”。`label` 是按钮文字，`text` 是学生点开后看到的讲解。

**新增课程**：在对应分组复制一节相近的课，换一个全站唯一的 `id`（例如 `g8-qiu-jing`），再填写课名、年级、册次、单元和正文。`warmup` 放课前提问；`focus` 的标题与讲解也会成为回忆卡；`activity` 放探究任务与选项；`quiz` 放随堂练习。题目的 `answer` 从 0 开始计数：A 填 0，B 填 1，C 填 2。调整选项顺序时，一并核对答案和解析。

**下架课程**：从这个分组移除该课的完整条目，检查前后条目之间的逗号。提交并发布后，公开课目录就会更新。

课程文件和提交记录是公开的，只放准备给学生看的内容。视频添加方法、提交步骤和发布后的检查示例见[教师操作指南](../teacher/README.md)。
