# 锦安老师的公开课

「跟锦安读一句」面向一至九年级的语文阅读与表达，另设文史拓展。首课是四年级《题西林壁》。也可以从书架依次选择科目、年级和单元，例如“语文 → 七年级 → 上册 · 第二单元”进入《咏雪》。[打开公开课堂](https://fengxy0725.github.io/jinan-classroom/)

首页页脚可以预览、下载宣传海报。把海报发到班级群，或按 A4 纵向打印，学生扫描图上的二维码即可进入公开首页。[查看宣传海报](./assets/classroom-poster.png)

## 课程与互动

内置课程库有 184 节课和 371 道带解析的随堂题。其中 169 节初中语文讲义根据 233 份课件编写，其余 15 节为小学语文、历史启蒙和初中历史示范课。在线书架的数量随教师发布、更新或撤下课程而变化。

| 年级 | 上册讲义 | 下册讲义 | 纳入的语文课件 |
| --- | ---: | ---: | ---: |
| 七年级 | 26 | 35 | 107 份 |
| 八年级 | 19 | 41 | 68 份 |
| 九年级 | 21 | 27 | 58 份 |

同一篇目的多个课时可以在讲义内展开。写作、名著和复习课按实际专题编目。原始 PPT、PPTX 保存在教师自己的资料目录。

学生可以先作答，再对照解析重新练习。“合上讲义 · 回忆卡”支持先写或口述解释、翻开讲解、自评掌握程度，难点会回到队尾。学生的草稿与答案只在当前页面使用。

## 教师工作台

从首页的“教师登录”进入 GitHub Pages 的教师工作台。首次点击“教师登录”后，前往原工作台验证教师账号；验证成功即回到 GitHub 上的教师页面。课程编辑、视频与访问记录仍通过私有后台读写。教师可以查看按时间排列的匿名页面访问记录，上传、播放教学视频。访问记录包含打开页面的时间与页面名称，一人反复访问可以产生多条记录。离线浏览、网络拦截或未成功送达的记录不会显示。

当前教学视频支持 MP4、WebM，每个文件上限 64 MiB。教师发布的课程可附公开视频与文字稿，学生打开该课即可播放、展开文字稿。公开站每次打开页面都向工作台读取发布状态，若连接失败，可在页面上重新读取。[打开教师工作台](https://fengxy0725.github.io/jinan-classroom/teacher/)

教师凭据只在原工作台域名输入。刷新或离开 GitHub 教师页后需再次验证。编辑期间会话到期时，保持原标签页打开并点击“重新验证并继续”，验证窗口返回后可以继续填写，随后再执行保存。退出会撤销当前授权，并锁定同一站点其他打开的教师工作台。

## 在电脑上试用

双击项目中的 `index.html` 即可浏览内置课程的离线版本。可以逐级浏览目录，也可以直接搜索课名。进入讲义后，点击顶部的单元名可以回到同单元选课。在线发布变更与视频以公开网页为准。

也可以在项目文件夹里打开终端，运行以下命令。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

用浏览器打开 [本机预览](http://127.0.0.1:8000/)。HTTP 预览与公开网站同样需要工作台允许该来源读取已发布课程；只检查内置讲义时可直接双击 HTML。按 `Ctrl+C` 结束本机预览。

## 把一份新课件做成网页

1. **交给助手。** 在对话中上传课件，注明科目、年级、册次、单元和课时。例如“这是语文八年级上册第三单元《三峡》第一课时，请新增一节互动课”。拓展课可以用自己的主题作单元名。
2. **确定学生要做什么。** 从课件选出一个明确目标，保留支持这个目标的文字、史料或例句。把一个关键观察改成可点选的活动，再设计至少两道能检验理解的选择题。
3. **接入目录。** 在对应的课程数据文件末尾添加一条 `window.lessons.push({...})` 即可。每节课需要独一无二的 `id`。若另建数据文件，请在 `index.html` 和 `lesson.html` 各增加一行 `<script defer src="./lessons/新文件名.js"></script>`，放在已有课程脚本旁、页面交互脚本之前。
4. **走完一遍课堂。** 本地打开首页，用对应年级和学科找到新课。依次点开探究项，分别选一次错误和正确答案，检查文字与解析，再提交更新。

### 可复制的课程数据

下面是一节独立的小练习，演示数据格式。文字、题目、参考资料均可按实际课件替换。

```js
window.lessons.push({
  id: "dongci-xiaolianxi", // 使用小写英文字母、数字和短横线，发布后保留此编号
  title: "读动词，想画面",
  grade: 2,                // 填数字 1 至 9
  subject: "语文",         // 填“语文”或“历史”
  term: "拓展",            // 与课件一致，可填“上册”“下册”或“拓展”
  unit: "拓展 · 动词与画面", // 同册同单元的课使用相同名称，如“上册 · 第三单元”
  type: "示范课",          // 原创示范课填写此项，课件改编可省略
  genre: "词句练习",
  summary: "读三个动词，排一排小猫回家的动作。",
  // source、sources、credit、reference 仅作课程维护资料，不在课堂页面展示
  // reference 可填写 { title: "史料名称", url: "https://..." }
  warmup: "小猫“走”上窗台和“跃”上窗台，你会怎样用手演给同桌看？",
  focus: [
    { label: "读句子", text: "小猫跃上窗台，蹭了蹭花盆，蜷成一个毛团。找出描写小猫动作的词。" }
  ],
  activity: {
    prompt: "选一个动词，用手演出来，再打开提示。",
    choices: [
      { label: "跃", text: "手掌轻轻向上一跳，再落到桌面。哪一瞬间手离开了桌面？" },
      { label: "蜷", text: "将张开的手指慢慢收拢。小猫的身体也缩得圆圆的。" }
    ]
  },
  quiz: [
    {
      question: "哪个词最能让你看见小猫跳上窗台？",
      options: ["蜷", "跃", "蹭"],
      answer: 1, // 选项从 0 开始计数，1 表示第二项
      explanation: "“跃”写小猫身子腾起，表现出跳的动作。"
    },
    {
      question: "小猫最后是什么样子？",
      options: ["身体缩成一团", "正向上跳", "正在推花盆"],
      answer: 0,
      explanation: "“蜷”写身体弯曲收拢，“毛团”写出它蜷好后的模样。"
    }
  ]
});
```

## 用 GitHub Pages 公开发布

项目按公开仓库 `fengxy0725/jinan-classroom` 准备，使用 GitHub Pages 的分支发布方式。拥有仓库管理权限的账号可按下列步骤操作。

1. 在 GitHub 创建或打开上述仓库，使用 `main` 分支。将项目内的网站文件和文件夹放在仓库根目录，使 `index.html` 与 `lesson.html` 直接可见。
2. 到仓库的 **Settings → Pages**，在 **Build and deployment → Source** 选择 **Deploy from a branch**。
3. 选择 **main** 和 **/(root)**，点击 **Save**。等仓库 **Actions** 中的 Pages 部署任务成功后，在 **Settings → Pages → Visit site** 获取实际公开网址。
4. 以后新增课程，只需将修改过的站点文件提交到 `main`。部署成功后，从公开网址点进新课，确认首页和练习都能打开。[GitHub 官方分支发布说明](https://docs.github.com/zh/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
